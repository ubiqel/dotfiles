# Commit conventions

- Use Conventional Commits by default, for example `feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`, `test: ...`, or `chore: ...`.
- If the repository already uses a different commit style, follow the repository's existing style instead.
- Every commit message must explain what the change contains and why it was made. Use the subject for the summary and the body for the reason when it is not obvious.
